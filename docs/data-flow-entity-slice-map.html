Story to lore

Everlink Swimlane

Selection-driven entity creation or extension, target selection, pending placement, and anchored slice commit.

1. Select story textEditor selection captures text, from/to, and screen anchor for the affordance.
2. Resolve sessionChooser creates or selects Entity, then upserts an explicit MatchingRule for the source text.
3. Choose targetExisting or newly created Document opens in panel or main surface.
4. Place pending sliceCursor or range becomes pending rails; empty cursor can auto-fill source text on commit.
5. Commit fresh anchorFlush persistence, read editor snapshot, build TextAnchor, call createSlice, repaint boundaries.
LayerResponsibilityKey files
Renderer sessionEntity choice, rule attachment, target document choice.useEverlinkSession.ts
Renderer placementPending range, auto-fill, commit trigger.usePendingPlacement.ts
Shared commit helperFlushes, re-anchors against editor snapshot, calls IPC.everlinkShared.ts
Database transactionCreates Slice, SliceBoundary, EntitySlice; appends sliceCreated.WorkspaceRepository.ts, SliceRepository.ts

Lore or prose to entity

Everslice Swimlane

Same-document selection-to-entity binding without target-document routing.

1. Select passageNon-empty main editor selection is frozen when the modal opens.
2. Pick entityChooser filters loaded Entity and MatchingRule data; author selects existing or names new.
3. Optional createNew Entity is created first so the slice link is never orphaned.
4. Same-doc anchorFrozen selection positions bind against the active document editor snapshot.
5. Create sliceThe same createSlice path writes Slice, SliceBoundary, and EntitySlice.
Structural difference: Everslice sets targetDocumentId equal to sourceDocumentId and never opens the placement panel.

Edit survival

Document Edit And Boundary Repair Flow

Every prose edit can move anchors forward without letting stale ranges silently point at wrong lore.

1. Prose transactionProseMirror emits steps and inverse steps from an editor transaction.
2. Append historyDocument steps and optional checkpoint are written before projection update.
3. Update projectionDocument currentVersion, contentJson, plainText, and metrics move forward.
4. Remap boundariesMapping moves SliceBoundary TextAnchors through the same step set.
5. Surface resultresolved/repaired/ambiguous/invalid controls preview and repair UX.
ResolutionMeaningRequired behavior
resolvedMapping preserved the range confidently.Preview and decoration can render normally.
repairedExact text plus context recovered the range.Render with visible confidence if needed.
ambiguousSeveral plausible ranges exist.Fail closed; never pick one silently.
invalidRange collapsed, deleted, or cannot be found.Surface repair state; do not preview wrong content.
